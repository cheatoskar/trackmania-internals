Shader constant layout of TM Vibrant Shaders (own pipeline, not the game's): pixel shaders ps_3_0 in shaders\tmvs.hlsl, compiled by fxc at build time (TMVS_ENTRIES in CMakeLists must match kEntryPoints in pipeline.cpp); constants c0-c31 and c34-c36 per frame, c32/c33 per pass, c35 = height-map origin (upload again after updateHeightMap re-centres, every ~40 m), c43 = game sun; samplers s0-s9 (s7 = 3D cloud noise); PS_Lighting at 3897/3900 slots (ps_3_0 4096-slot limit hit in 1.3.0); `[unroll]` on noise loops made PS_Sky compile 120 s -> use `[loop]`; ps_3_0 has no bitwise ops. source tmvs notes, GOTCHA.md; status verified.

Pipeline order per main camera (tmvs\docs\how-it-works.md): geometry (linear depth, normals), height map splat, AO + shadows + blur, volumetric light + bounce GI (quarter res), sky + clouds, SSR + neon spill, lighting in HDR, neon trail, DOF/motion blur/light shafts/bloom/auto exposure/tone map/grade, FXAA/TAA/CAS/lens drops, particles (rain) on finished image. status verified (doc).

Quirk list (see GOTCHA.md): projection jitter struct (transposed first at [0..15], D3D layout at +0x40); TAA erases thin particles (draw after TAA); replay-camera motion blur clamped to 2.5% of screen; Snow on car (carBody finds road from depth beside car; ignores surfaces >1.6 m below); Intel Arc runs DX9 via D3D9On12 (slow, do not scale FPS); previewer uses D3D9Ex when game runs fullscreen. status verified.

ManiaPlanet differences: see `games/maniaplanet`. Engine options analysis (DX11 for TMNF not worth it; hybrid not recommended; TM2 port needs full new backend; per-material shader replacement feasible via the D3DXCompileShader hook): tmvs\docs\engine-options.md. status verified (analysis) / inferred (effort estimates).

TM2 modpack/Hide-car/overlap notes: OverlapFix not buildable in TM2 without a draw capture (377 Block_TDSN_DefWrite_p draws fall into only 35 texture groups, engine sorts by material not block; no block ID). tmvs-notes\agent-out\tm2-overlap.md; verified.

## Findings from test rounds (own notes)

| Finding | Source | Status |
|---|---|---|
| Moon: `CMotionManagerWeathers::UpdateAsync` (TMNF 0x572c30 / TMUF 0x572cb0) takes the sector's directional light (GxLight at +0xc4, CSceneLight at +0xc8); when the moon is brighter than the sun it builds a horizontal moon direction -> `GmMat3::SetDOV` -> CSceneLight vtable +0x88 (SetLocation) -> `GxLight::SetBaseRGB`. TMUF checked byte for byte | own notes | verified |
| Night light is baked at map load (`CHmsPackLightMap`, IsNight; RenderLighting 0x545d60 -> RenderLightDir 0x544f60 into PreLightGen: dome, moon with shadows, lamps) | own notes | verified |
| Lightmap cache `C:\ProgramData\TrackMania\Cache\<UID>_<name>.<decoration>.LightMap.zip`; key ignores the light -> a mod that changes the light must bypass the cache (CacheIsUpToDate 0x5425a0 / TMUF 0x542450) | own notes | verified |
| Night overexposure in the mod came from guessing lamps in the 8-bit image; on real night maps the game's image is flat 255 on floodlit areas. Fix: take the engine's own light draws (EngineLights) plus a float scene target (GameHdr) | own notes | verified (player-confirmed) |
| Neon borders are plain `TDiff_Spec_Nrm` material (not additive, no telling name): found by colour instead | own notes | verified |
| TMUnlimiter overlapping blocks z-fight; the engine draws by block placement order; "last placed wins" via D3DRS_DEPTHBIAS ranked by placement, priority engine-off > booster > waypoints (blockinfo +0x11c) > normal | own notes | verified (in-game test) |
| After the replay editor, materials are reloaded without the map-load hook and addresses are reused: per-address material caches go stale (dirt reflections) | own notes | verified |
| Lighting/tone changes: one change per in-game test; compare offline captures against the last confirmed shader | own notes | verified |
| Minimap from block meshes: block +0x30 mobil -> item -> solid/corpus -> CPlugTree -> visual keeper | own notes | verified (used in code) |
| Pixel-shader constant registers are a shared resource: three feature branches developed in parallel all claimed `c47`. Keep a register table and check it on every merge | own notes | verified |
| Car position guessed from a few depth samples in screen space (neon trail) flickered and jumped in curves; the engine's interpolated vehicle location (`CSceneMobil` vtable slot 32, see [engine-hooks.md](../games/tmnf/engine-hooks.md)) fixed it | own notes | verified (player-confirmed) |
| Video export sound via Windows process-loopback capture: after Stop/Reset/Start the same capture client delivered only silence; create a fresh client per export | own notes | verified |
| A mod DLL that imports `d3d9.dll` statically failed with 0xc000007b on TMUF (seen with a standalone clip recorder); proxies must load the system d3d9 by full path at runtime ([loaders-and-hooks.md](../modding/loaders-and-hooks.md)) | own notes | verified (observed), cause inferred |
