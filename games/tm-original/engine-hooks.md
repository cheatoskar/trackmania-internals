# TrackMania Original: getting into the process, engine hooks

Exe: `TMORIGINAL.EXE` Online Patch v2, SHA-256 `75e129d7...`, PE timestamp `5d337477` ([README.md](README.md)). Addresses: [addresses.md](addresses.md). Everything here is static (2026-11-11); nothing was run in game yet. Status per row.

Source keys: `gx` = Ghidra 12.1.2 xrefs (fresh headless analysis of this exe); `refl` = the engine's reflection tables ([scripts/re/classinfo.py](../../scripts/re/classinfo.py)); `hh` = Horizon Host (own mod host for the old games), branch `tmo`, files named in the row; `kit` = Horizon Porting Kit atlas; `sun` = [../tm-sunrise/](../tm-sunrise/README.md).
